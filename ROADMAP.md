# Дорожная карта разработки языка APS (ROADMAP)

Разработка языка **APS (Advanced Performance Systems)** выполняется последовательно в 5 инженерных этапов. Переход к следующему этапу осуществляется только после выполнения всех критериев завершения предыдущего этапа.

---

## Этап 1: Полная техническая спецификация APS (`v0.1.0-spec`)
- [x] Формулировка философии языка и принятие базовых архитектурных решений (`DECISIONS.md`).
- [ ] Создание полной спецификации языка `spec/APS_LANGUAGE_SPEC.md` (30 разделов).
- [ ] Формализация архитектуры памяти `spec/AMA_SPEC.md` (четыре уровня памяти, `read`/`write`/`take`, 30+ формальных примеров корректного и ошибочного кода).
- [ ] Разработка формальной грамматики EBNF и правил синтаксиса `spec/APS_SYNTAX.md`.
- [ ] Спецификация системы диагностик и кодов ошибок `spec/DIAGNOSTICS.md`.
- [ ] Подготовка 30+ эталонных спецификационных примеров в `examples/specification/`.
- [ ] Критический аудит спецификации на отсутствие противоречий.

## Этап 2: Создание базового компилятора APS (`v0.2.0-compiler`)
- [ ] Инициализация Rust-проекта компилятора и модульной структуры каталогов.
- [ ] Реализация `lexer` (токенизация, позиции строк/столбцов, литералы, комментарии, тесты).
- [ ] Реализация `parser` и `ast` (полный разбор конструкций языка по грамматике).
- [ ] Реализация `semantic` и `types` (проверка областей видимости, вывод типов, проверка обобщений и структур).
- [ ] Реализация базового анализатора памяти `ama` (проверка `read`, `write`, `take`, отслеживание перемещений).
- [ ] Построение промежуточных представлений: `HIR` → `MIR` → `APS IR`.
- [ ] Реализация `codegen` с генерацией LLVM IR и компиляцией через LLVM (`clang`) в нативные исполняемые файлы (`.exe` / ELF / Mach-O).
- [ ] Реализация CLI компилятора (`aps new`, `aps check`, `aps build`, `aps run`, `aps test`, `aps fmt`, `aps clean`, `aps doc`, `aps version`).

## Этап 3: Полноценная реализация языка и экосистемы (`v0.5.0-ecosystem`)
- [ ] Расширение компилятора до полной поддержки спецификации (`enum`, `match`, замыкания, `region`, `Result`/`Option`, `?`, модули, `async`/`await`, потоки, FFI).
- [ ] Полная реализация движка AMA (граф владения, вычисление мест деаллокации CTFP, Escape Analysis, Region Inference, проверка потокобезопасности).
- [ ] Разработка стандартной библиотеки `std/` (`core`, `memory`, `string`, `collections`, `math`, `io`, `fs`, `net`, `time`, `process`, `thread`, `sync`, `async`, `crypto`, `encoding`, `testing`, `platform`).
- [ ] Создание пакетного менеджера `apm` (`init`, `add`, `remove`, `update`, `install`, `build`, `publish`, `search`, lock-файлы и контрольные суммы SHA-256).
- [ ] Разработка инструментов разработчика: форматтер (`aps fmt`), линтер (`aps lint`), генератор документации (`aps doc`), сервер языкового протокола LSP (`aps-lsp`).
- [ ] Создание 10 реальных прикладных и системных проектов в `examples/real_world/`.

## Этап 4: Производительность, безопасность и стабильность (`v0.9.0-hardened`)
- [ ] Реализация оптимизирующих проходов компилятора APS (Constant Folding, Dead Code Elimination, Inlining, CSE, Loop Optimization, Escape Analysis, Memory Layout, SIMD/LTO).
- [ ] Комплексное тестирование безопасности памяти AMA (compile-fail и runtime-safety тесты на UAF, double-free, dangling references, region escape, гонки данных, границы FFI).
- [ ] Создание воспроизводимого набора бенчмарков `benchmarks/` (сравнение APS с Rust и C на 14 категориях задач).
- [ ] Настройка конфигурации CI/CD и стресс-тестирования компилятора на больших проектах.

## Этап 5: Полный учебный курс, справочник и релиз (`v1.0.0`)
- [ ] Создание полного русскоязычного учебника `learning/` (22 главы от основ устройства компьютера до системной и серверной разработки на APS).
- [ ] Разработка курса по внутреннему устройству компилятора (`APS Compiler Internals`).
- [ ] Создание банка из 300+ практических упражнений (5 уровней сложности) с решениями и тестами.
- [ ] Создание 15 сквозных практических проектов с разбором архитектуры и рабочим кодом.
- [ ] Написание полного справочника языка и стандартной библиотеки (`learning/reference/`).
- [ ] Автоматическая верификация примеров кода учебника настоящим компилятором APS.
- [ ] Итоговая сквозная проверка и выпуск `RELEASE_REPORT.md`.
