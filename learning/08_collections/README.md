# Глава 08: Стандартные коллекции и Структуры Данных в APS

В системном программировании выбор структуры данных напрямую определяет производительность приложения. В APS стандартная библиотека `std::collections` предоставляет высокоэффективные коллекции, спроектированные с учётом архитектуры процессоров, кэш-линий и модели памяти AMA.

---

## 1. Динамический массив: `Vector<T>`

`Vector<T>` — наиболее часто используемая коллекция в APS. Элементы хранятся в непрерывном блоке оперативной памяти, что обеспечивает максимальную локальность ссылок в L1/L2 кэшах CPU.

```aps
import std::collections::Vector;

fn vector_operations() {
    // Выделение с начальной емкостью для избежания повторных аллокаций
    var items = Vector::with_capacity(100);

    // Добавление элементов: O(1) амортизированное
    items.push(10);
    items.push(20);
    items.push(30);

    // Индексация с защитной проверкой границ (aps_bounds_check)
    let val = items[1]; // 20

    // Удаление с конца: O(1)
    let last = items.pop(); // Some(30)
}
```

## 2. Хеш-таблица: `HashMap<K, V>`

`HashMap<K, V>` использует схему Robin Hood Hashing с открытой адресацией. Это снижает дисперсию поиска и предотвращает деградацию производительности при коллизиях:

```aps
import std::collections::HashMap;

fn hashmap_example() {
    var cache = HashMap::new();
    cache.insert("user:101", "Алибек");
    cache.insert("user:102", "Дмитрий");

    match cache.get("user:101") {
        Some(name) => print("Пользователь найден: " + name),
        None => print("Запись отсутствует"),
    }
}
```

## 3. Кольцевой буфер: `RingBuffer<T>`

Для очередей задач (Work Queues) и обработки сетевых пакетов стандартная библиотека предоставляет `RingBuffer<T>` с фиксированным размером:

```aps
import std::collections::RingBuffer;

let mut ring = RingBuffer::new(1024);
ring.push_back(packet);
let oldest = ring.pop_front(); // O(1) строго детерминированное время!
```

## 4. Итераторы и безопасность памяти

При итерации по коллекции компилятор AMA гарантирует, что коллекция не будет непреднамеренно изменена во время цикла (защита от Iterator Invalidation):

```aps
var numbers = Vector::new();
numbers.push(1);
numbers.push(2);

// Во время этого цикла numbers заимствован как `read`
for n in numbers.iter() {
    print(n);
    // numbers.push(99); // ОШИБКА E0302: Нельзя модифицировать коллекцию во время итерации!
}
```
Такой подход делает алгоритмы на APS надёжными и устойчивыми к багам синхронизации.
