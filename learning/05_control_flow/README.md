# Глава 05: Управление потоком выполнения и детерминизм в APS

В этой главе рассматриваются управляющие конструкции APS: ветвления, циклы, сопоставление с образцом и гарантированное освобождение ресурсов с помощью `defer`.

---

## 1. Ветвление `if` / `else` как выражение

В APS конструкция `if` является выражением (Expression), то есть возвращает значение. Это устраняет потребность в тернарном операторе `?:`:

```aps
let score = 85;
let grade = if score >= 90 {
    "Отлично"
} else if score >= 75 {
    "Хорошо"
} else {
    "Удовлетворительно"
};

print(grade); // "Хорошо"
```

Все ветви выражения `if` обязаны возвращать значения строго одинакового типа.

## 2. Исчерпывающее сопоставление `match`

Конструкция `match` обеспечивает мощный механизм ветвления по значению или структуре:

```aps
let status_code: i32 = 404;

let message = match status_code {
    200 => "OK",
    301 | 302 => "Redirect",
    400 => "Bad Request",
    404 => "Not Found",
    500..=599 => "Server Error",
    _ => "Unknown Code", // Подстановочный шаблон по умолчанию
};
```

### Сопоставление с охранными условиями (Match Guards):
```aps
let number = 15;
match number {
    x if x % 15 == 0 => print("FizzBuzz"),
    x if x % 3 == 0  => print("Fizz"),
    x if x % 5 == 0  => print("Buzz"),
    x => print(x.to_string()),
}
```

## 3. Циклы в APS: `while`, `for`, `loop`

### 3.1. Цикл `while`
Выполняется до тех пор, пока истинно условие:
```aps
var counter = 0;
while counter < 5 {
    print("Итерация: " + counter.to_string());
    counter += 1;
}
```

### 3.2. Цикл `for .. in`
Используется для перебора диапазонов и коллекций:
```aps
// Полуоткрытый диапазон 0..5 (0, 1, 2, 3, 4)
for i in 0..5 {
    print(i);
}

// Закрытый диапазон 1..=5 (1, 2, 3, 4, 5)
for i in 1..=5 {
    print(i);
}

// Итерация по коллекции
let items = ["Яблоко", "Груша", "Апельсин"];
for fruit in items {
    print(fruit);
}
```

### 3.3. Бесконечный цикл `loop` и возврат значения из `break`
Конструкция `loop` оптимизируется компилятором как безусловный переход `jmp`:
```aps
var attempts = 0;
let success_step = loop {
    attempts += 1;
    if poll_network() {
        break attempts; // Возврат значения из цикла loop!
    }
    if attempts >= 10 {
        break -1;
    }
};
```

## 4. Гарантированная очистка: инструкция `defer`

Инструкция `defer` планирует выполнение блока кода ровно в момент выхода из текущей области видимости `{}` (независимо от того, произошёл выход через `return`, `break` или аварийную ошибку):

```aps
fn process_transaction(path: String) -> Result<(), Error> {
    let file = File::open(path)?;
    defer file.close(); // Будет выполнен ВСЕГДА при выходе из функции!

    let lock = acquire_lock()?;
    defer lock.release();

    // Основная бизнес-логика
    file.write_all(b"DATA")?;
    Ok(())
}
```

Стек `defer` выполняется в обратном порядке (LIFO — Last In, First Out). Это гарантирует детерминированное закрытие ресурсов без необходимости в громоздких блоках `try/finally`.
