# Глава 13: Многопоточность и Параллельные Вычисления в APS

APS спроектирован для эффективного масштабирования на современных многоядерных процессорах с десятками и сотнями аппаратных ядер. Модель памяти AMA гарантирует полное отсутствие гонок данных (Data-Race Free).

---

## 1. Нативные системные потоки: `std::thread`

APS создаёт настоящие потоки операционной системы с индивидуальными стеками:

```aps
import std::thread;

fn parallel_compute() {
    let handle = thread::spawn(|| {
        var sum: i64 = 0;
        for i in 1..=1_000_000 {
            sum += i;
        }
        sum
    });

    // Ожидание завершения потока и получение результата:
    let total = handle.join();
    print("Сумма миллиона чисел: " + total.to_string());
}
```

---

## 2. Безопасная передача сообщений по каналам (Channels)

В APS данные между потоками передаются через типизированные каналы с передачей владения (`take T`). После отправки данных в канал передающий поток больше не имеет доступа к объекту, что исключает необходимость блокировок при чтении:

```aps
import std::sync::channel;

fn channel_pipeline() {
    let (tx, rx) = channel::bounded(64);

    thread::spawn(|| {
        for id in 1..=10 {
            let task = Task::new(id);
            tx.send(take task); // Передача владения задачей
        }
    });

    while let Some(task) = rx.recv() {
        process_task(task);
    }
}
```

## 3. Разделяемые изменяемые данные: `Mutex<T>`

Если нескольким потокам необходимо модифицировать один и тот же объект в памяти, доступ оборачивается в `Mutex<T>`:

```aps
import std::sync::Mutex;

let counter = Mutex::new(0);

// Захват блокировки через RAII Guard
{
    let mut guard = counter.lock();
    *guard += 1;
} // При выходе из блока guard освобождает мьютекс
```

## 4. Сверхбыстрые атомарные примитивы (Lock-Free Atomics)

Для метрик высокой частоты и счётчиков запросов APS предоставляет атомарные типы из модуля `std::sync::atomic`:

```aps
import std::sync::atomic::{AtomicUsize, Ordering};

let request_counter = AtomicUsize::new(0);

// Инкремент без блокировок ОС (транслируется в процессорную инструкцию LOCK XADD)
request_counter.fetch_add(1, Ordering::SeqCst);
```
Это обеспечивает производительность в десятки миллионов операций в секунду на одно ядро процессора.
