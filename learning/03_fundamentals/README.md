# Глава 03: Фундаментальный Синтаксис, Переменные и Области Видимости в APS

В этой главе мы познакомимся с базовым синтаксисом APS: правилами объявления неизменяемых и изменяемых переменных, константами времени компиляции, механизмом затемнения имён (Shadowing) и лексическими областями видимости.

---

## 1. Неизменяемые переменные по умолчанию (`let`)

В философии APS неизменяемость (Immutability) является стандартом по умолчанию:
```aps
let max_connections: i64 = 1000;
let server_name = "APS-Master-01"; // Тип &str выводится автоматически
```

Если вы попытаетесь перезаписать переменную, объявленную через `let`:
```aps
let balance: i64 = 500;
balance = 600; // ОШИБКА КОМПИЛЯТОРА!
```
Компилятор APS остановит сборку с дружественным сообщением:
```
error[E0042]: cannot assign twice to immutable binding 'balance'
  --> src/main.aps:2:1
   |
 1 | let balance: i64 = 500;
   |     ------- first assignment here
 2 | balance = 600;
   | ^^^^^^^^^^^^^ cannot assign to immutable variable
   |
   = help: to make this variable mutable, use 'var' instead of 'let'
```

---

## 2. Изменяемые переменные (`var`)

Если значение переменной должно изменяться в ходе выполнения программы, используйте ключевое слово `var`:

```aps
var current_count = 0;
current_count += 1;
current_count += 5;
print("Текущий счётчик: " + current_count.to_string());
```

---

## 3. Константы времени компиляции (`const`)

Константы объявляются ключевым словом `const`. В отличие от `let`, константы:
1. Вычисляются строго на этапе компиляции.
2. Не имеют ячейки памяти в стеке или куче во время выполнения (компилятор подставляет литералы напрямую в ассемблерные инструкции процессора).
3. По соглашению именуются заглавными буквами со знаком подчеркивания `SCREAMING_SNAKE_CASE`.

```aps
const BUFFER_SIZE: usize = 4096;
const MAX_PACKET_LEN: usize = BUFFER_SIZE * 4; // Вычисляется компилятором!
```

---

## 4. Затемнение переменных (Variable Shadowing)

APS поддерживает идиому затемнения переменных в той же или во вложенной области видимости. Это позволяет переиспользовать понятное имя переменной после её трансформации:

```aps
let input_raw = "   42   ";
let input_raw = input_raw.trim(); // Затемнение: убрали пробелы
let input: i64 = input_raw.parse().unwrap(); // Преобразование типа!
```
Затемнение не является перезаписью мутабельной ячейки: это создание нового независимого неизменяемого связывания.

---

## 5. Лексические области видимости (Block Scopes)

Каждый блок в фигурных скобках `{}` образует изолированную лексическую область видимости. Переменные, объявленные внутри блока, детерминированно уничтожаются при выходе из него:

```aps
let outer = 10;
{
    let inner = 20;
    print(outer + inner); // 30
}
// print(inner); // ОШИБКА E0101: Переменная 'inner' не найдена в этой области видимости!
```
Это свойство лежит в основе гарантий освобождения памяти RAII в модели AMA.
