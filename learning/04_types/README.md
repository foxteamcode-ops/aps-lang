# Глава 04: Статическая система типов и автоматический вывод типов в APS

В этой главе мы подробно изучим систему типов APS — основу надёжности и максимальной скорости программ. В APS типы проверяются строго во время компиляции, не допуская неявных преобразований и исключая целый класс ошибок приведения типов во время выполнения.

---

## 1. Архитектура системы типов APS

В APS все типы делятся на две основные категории:
1. **Примитивные скалярные типы (Primitives):** хранятся непосредственно в стеке или регистрах CPU.
2. **Составные и ссылочные типы (Compounds & References):** кортежи, структуры, перечисления, срезы и управляемые структуры данных.

```
                             Типы данных в APS
                                    │
          ┌─────────────────────────┴─────────────────────────┐
          ▼                                                   ▼
   Скалярные типы (Stack)                            Составные типы (AMA)
   ├─ Целые: i8..i64, u8..u64                         ├─ Кортежи: (T1, T2)
   ├─ Вещественные: f32, f64                          ├─ Структуры: struct
   ├─ Логический: bool                                ├─ Перечисления: enum
   ├─ Символьный: char (UTF-32)                       ├─ Массивы: [T; N]
   └─ Указатели размера: usize, isize                 └─ Коллекции: Vector, String
```

---

## 2. Числовые типы: строгая разрядность и переполнения

### Знаковые целые числа
- `i8` (от $-128$ до $127$)
- `i16` (от $-32\,768$ до $32\,767$)
- `i32` (от $-2^{31}$ до $2^{31}-1$)
- `i64` (от $-2^{63}$ до $2^{63}-1$) — целочисленный тип по умолчанию в 64-битных системах.
- `isize` — знаковое целое, совпадающее по размеру с указателем целевой архитектуры.

### Беззнаковые целые числа
- `u8` (от $0$ до $255$) — также используется как базовый байтовый тип `byte`.
- `u16` (от $0$ до $65\,535$)
- `u32` (от $0$ до $2^{32}-1$)
- `u64` (от $0$ до $2^{64}-1$)
- `usize` — размер адресного пространства, используется для индексации массивов и коллекций.

### Числа с плавающей точкой
- `f32` — одинарная точность (IEEE-754 Single Precision, 32 бита).
- `f64` — двойная точность (IEEE-754 Double Precision, 64 бита) — вещественный тип по умолчанию.

## 3. Логический и символьный типы

### Булев тип `bool`
Принимает строго два значения: `true` и `false`. Занимает 1 байт в памяти.
В APS булев тип **не приводится автоматически** к числам 0 или 1, как в C/C++:
```aps
let is_ready = true;
// if is_ready == 1 {} // ОШИБКА E0402: Type Mismatch!
if is_ready {}       // Корректно!
```

### Символьный тип `char`
Представляет скалярное значение Unicode (UTF-32 Codepoint) и занимает ровно 4 байта (32 бита). Поддерживает любые символы алфавитов мира и эмодзи:
```aps
let ch1: char = 'A';
let ch2: char = 'Я';
let ch3: char = '🚀';
```

## 4. Строковые типы: `String` vs `&str`

В APS строго разделяются два строковых типа:
1. `String`: динамическая строка в куче или арене памяти, владеющая буфером UTF-8 с возможностью изменения длины и конкатенации.
2. `&str`: строковый срез (толстый указатель на адрес и длину в байтах), позволяющий просматривать подстроки без копирования данных.

```aps
let greeting: String = "Привет, мир!".to_string();
let slice: &str = greeting[0..6]; // Срез первых 6 байт UTF-8
```

## 5. Запрет неявных приведений (No Implicit Casts)

В APS полностью отсутствуют неявные расширяющие или сужающие приведения (Implicit Promotions / Coercions). Сложение переменной `i32` и переменной `i64` без явного указания намерений программиста запрещено:

```aps
let small: i32 = 100;
let large: i64 = 2000;

// Ошибка E0402: cannot add i32 and i64
// let total = small + large;

// Правильно: явное приведение с помощью ключевого слова `as`
let total: i64 = (small as i64) + large;
```

## 6. Двунаправленный локальный вывод типов (Type Inference)

Компилятор APS использует алгоритм вывода типов на основе унификации Дамаса-Милнера в пределах области видимости функций:
```aps
let count = 42;          // Выводится как i64
let ratio = 3.14159;     // Выводится как f64
let name = "Алибек";     // Выводится как &str

var scores = Vector::new(); // Выводится как Vector<i64> после первого push
scores.push(100);
```

Если компилятор не может однозначно определить тип из контекста, он выдаёт понятную подсказку с предложением указать тип явно.
