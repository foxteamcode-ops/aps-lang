# Справочник: Ключевые слова APS (Keywords Reference)

В языке программирования **APS (Advanced Performance Systems)** зарезервировано ровно **36 ключевых слов**. Все ключевые слова являются зарезервированными идентификаторами и не могут использоваться в качестве имён переменных, структур, функций или модулей.

---

## Полная таблица ключевых слов

| Ключевое слово | Категория | Краткое назначение | Пример использования |
|---|---|---|---|
| `fn` | Декларация | Объявление функции или метода | `fn add(a: i64, b: i64) -> i64 { a + b }` |
| `let` | Переменные | Объявление неизменяемой локальной переменной | `let max_limit: i64 = 1000` |
| `var` | Переменные | Объявление изменяемой локальной переменной | `var counter = 0; counter += 1` |
| `const` | Константы | Объявление времени компиляции (Compile-Time Constant) | `const BUFFER_SIZE: usize = 4096` |
| `struct` | Пользовательские типы | Объявление составного типа структуры с полями | `struct User { id: i64, name: String }` |
| `enum` | Алгебраические типы | Объявление перечисления (Sum Type / Tagged Union) | `enum Status { Active, Suspended, Deleted }` |
| `trait` | Полиморфизм | Объявление интерфейсного контракта поведения | `trait Serializable { fn to_bytes(read self) -> Vector<u8>; }` |
| `impl` | Реализация | Блок реализации методов или трейта для типа | `impl User { fn new(id: i64) -> User { ... } }` |
| `type` | Псевдонимы | Определение синонима типа (Type Alias) | `type UserId = i64;` |
| `module` | Модульность | Объявление пространства имён или подмодуля | `module network;` |
| `import` | Модульность | Подключение внешнего модуля или символа | `import std::collections::Vector;` |
| `pub` | Видимость | Экспорт символа за пределы текущего модуля | `pub fn start_service() { ... }` |
| `extern` | FFI / Интероп | Объявление внешней C-функции без реализации | `extern "C" fn puts(s: *const u8) -> i32;` |
| `if` | Управление потоком | Условное ветвление (выражение или оператор) | `if balance > 0 { process() } else { reject() }` |
| `else` | Управление потоком | Альтернативная ветка условия `if` | `else if retry < 3 { retry += 1 }` |
| `match` | Pattern Matching | Исчерпывающий разбор структуры/значения по шаблону | `match res { Ok(v) => v, Err(e) => return }` |
| `while` | Циклы | Цикл с предусловием | `while running { poll(); }` |
| `for` | Циклы | Цикл по итерируемой коллекции или диапазону | `for item in items { print(item); }` |
| `in` | Циклы | Разделитель целевого итератора в цикле `for` | `for i in 0..10 { ... }` |
| `loop` | Циклы | Бесконечный цикл с выходом через `break` | `loop { let msg = queue.pop(); break; }` |
| `break` | Циклы | Немедленное прерывание цикла с опциональным значением | `if found { break item; }` |
| `continue` | Циклы | Переход к следующей итерации цикла | `if item.is_empty() { continue; }` |
| `return` | Управление потоком | Возврат значения из функции | `return Result::Err("timeout");` |
| `defer` | Детерминизм | Регистрация отложенного действия при выходе из блока | `defer file.close();` |
| `read` | AMA Capability | Разрешение только для чтения ссылки на объект | `fn inspect(driver: read Driver) { ... }` |
| `write` | AMA Capability | Эксклюзивное право на изменение объекта | `fn update(driver: write Driver, val: i64) { ... }` |
| `take` | AMA Capability | Полная передача владения объектом (Move Semantics) | `fn consume(driver: take Driver) { ... }` |
| `region` | AMA Уровень 3 | Создание лексической арены памяти $O(1)$ | `region arena { let node = arena.alloc(Data); }` |
| `share` | AMA Уровень 4 | Заморозка изменяемого объекта в Shared Immutable | `let shared_cfg = share cfg;` |
| `shared` | AMA Уровень 4 | Квалификатор типа для потокобезопасного объекта | `let cfg: shared Config = load();` |
| `unsafe` | Системный уровень | Блок для низкоуровневых операций и вызовов FFI | `unsafe { ptr_write(addr, val); }` |
| `async` | Асинхронность | Объявление асинхронной функции или блока | `async fn fetch_data() -> Result<Data, Error>` |
| `await` | Асинхронность | Ожидание завершения Future без блокировки потока | `let res = fetch_data().await;` |
| `spawn` | Параллелизм | Запуск легковесной задачи или потока | `spawn { worker_loop(); };` |
| `true` | Литерал | Булево значение истина | `let is_ready: bool = true;` |
| `false` | Литерал | Булево значение ложь | `let has_error: bool = false;` |
| `as` | Приведение типов | Явное безопасное приведение типов (Cast) | `let b: u8 = val as u8;` |

---

## Правила разрешения идентификаторов

1. Ни одно из перечисленных 36 слов не может быть именем переменной, поля структуры или параметра.
2. Попытка объявить `let for = 10;` вызывает ошибку компилятора:
   ```
   error[E0001]: expected identifier, found keyword 'for'
   ```
3. Все ключевые слова регистрозависимы (case-sensitive) и пишутся строго в нижнем регистре (за исключением будущих контекстных модификаторов, если они будут введены).
