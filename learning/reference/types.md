# Справочник: Система типов APS (Type System Reference)

Система типов **APS** является статической, строго типизированной с полным сохранением безопасности типов на этапе компиляции (Compile-Time Type Safety) и автоматическим выводом типов (Bidirectional Local Type Inference).

---

## 1. Базовые скалярные типы (Primitives)

| Тип | Размер | Диапазон значений | Выравнивание (Align) |
|---|---|---|---|
| `bool` | 1 байт | `true` или `false` | 1 байт |
| `i8` | 1 байт | $-128 \dots 127$ | 1 байт |
| `u8` | 1 байт | $0 \dots 255$ (также используется для сырых байтов) | 1 байт |
| `i16` | 2 байта | $-32\,768 \dots 32\,767$ | 2 байта |
| `u16` | 2 байта | $0 \dots 65\,535$ | 2 байта |
| `i32` | 4 байта | $-2^{31} \dots 2^{31}-1$ | 4 байта |
| `u32` | 4 байта | $0 \dots 2^{32}-1$ | 4 байта |
| `i64` | 8 байт | $-2^{63} \dots 2^{63}-1$ (целочисленный тип по умолчанию) | 8 байт |
| `u64` | 8 байт | $0 \dots 2^{64}-1$ | 8 байт |
| `f32` | 4 байта | IEEE-754 одинарной точности | 4 байта |
| `f64` | 8 байт | IEEE-754 двойной точности (вещественный тип по умолчанию) | 8 байт |
| `char` | 4 байта | Допустимый скалярный код Unicode (UTF-32 codepoint) | 4 байта |
| `usize` | 8 байт (x64) | Зависит от разрядности целевой архитектуры процессора | Размер указателя |
| `isize` | 8 байт (x64) | Знаковое смещение адресного пространства | Размер указателя |
| `()` | 0 байт | Тип Unit (эквивалент `void`, не занимает памяти) | 1 байт |

## 2. Составные типы (Compound Types)

### 2.1. Кортежи (Tuples)
Фиксированная последовательность разнородных типов, упакованная в стек:
```aps
let pair: (i64, String) = (42, "APS");
let first = pair.0;
let second = pair.1;
```

### 2.2. Массивы фиксированного размера (Fixed Arrays)
Непрерывный сегмент элементов одинакового типа, размещаемый непосредственно в стеке:
```aps
let buffer: [u8; 1024] = [0u8; 1024];
```

### 2.3. Срезы (Slices)
Толстый указатель (Fat Pointer: указатель на данные + длина):
```aps
let slice: &[u8] = buffer[0..128];
```

### 2.4. Строки (`String` и `&str`)
- `String`: управляемый буфер UTF-8 в куче с динамическим изменением размера (содержит указатель, емкость `capacity` и длину `len`).
- `&str`: неизменяемое окно (срез) в строковые данные.

## 3. Алгебраические типы данных (Algebraic Data Types)

### 3.1. Структуры (`struct`)
Определяют произведение типов (Product Types). Поля по умолчанию приватны для модуля.
```aps
struct ConnectionPool {
    host: String,
    port: u16,
    max_conns: usize,
    active: bool,
}
```

### 3.2. Перечисления (`enum` с полезной нагрузкой)
Определяют сумму типов (Sum Types / Tagged Unions). Представлены в памяти как дискриминант (`tag`) + объединённый блок памяти наибольшего варианта.
```aps
enum NetworkPacket {
    Ping,
    Message(String),
    BinaryPayload([u8; 64]),
    Disconnect { reason: String, code: u32 },
}
```

### 3.3. Стандартные типы `Option<T>` и `Result<T, E>`
```aps
enum Option<T> {
    Some(T),
    None,
}

enum Result<T, E> {
    Ok(T),
    Err(E),
}
```

## 4. Свойства типов и семантика копирования

1. **Типы `Copy`:** типы, для которых передача значения дублирует байты в стеке без изменения владения (`i8..i64`, `u8..u64`, `f32`, `f64`, `bool`, `char`, кортежи из типов `Copy`).
2. **Типы `Move` (Non-Copy):** типы, владеющие системными ресурсами или памятью в куче (`String`, `Vector<T>`, `File`, сокеты). При передаче в функции или переменные вступает в силу семантика переноса (Managed Ownership).
3. **Разрешения доступа (Capabilities):**
   - `read T`: неизменяемая ссылка.
   - `write T`: эксклюзивная изменяемая ссылка.
   - `take T`: передача владения объектом.
