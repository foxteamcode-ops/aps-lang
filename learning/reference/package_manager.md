# Справочник: Менеджер пакетов APM (Package Manager Reference)

**APM (Advanced Package Manager)** — официальный пакетный менеджер и система управления сборкой для языка APS. Поставляется в виде утилиты `apm` (или `apm.exe`).

---

## 1. Команды утилиты APM

```bash
apm <command> [args]
```

| Команда | Описание |
|---|---|
| `apm new <project_name>` | Создание нового проекта с готовым шаблоном и манифестом `Apm.toml` |
| `apm init` | Инициализация конфигурации APM в существующем каталоге |
| `apm add <package_name> [--version <ver>]` | Добавление внешней зависимости в проект |
| `apm remove <package_name>` | Удаление зависимости из манифеста |
| `apm update` | Обновление дерева зависимостей до совместимых версий |
| `apm build [--release]` | Запуск сборки проекта через компилятор `aps` |
| `apm test` | Запуск тестов проекта |
| `apm vendor` | Локализация всех внешних зависимостей в директорию `vendor/` для offline-сборки |
| `apm publish` | Публикация пакета в центральный или корпоративный реестр APM |

---

## 2. Формат манифеста `Apm.toml`

```toml
[package]
name = "hyper_service"
version = "1.0.0"
authors = ["Advanced Systems Team <team@aps-lang.org>"]
edition = "2026"
license = "MIT OR Apache-2.0"
description = "High-performance distributed service written in APS"

[dependencies]
aps_json = "0.4.2"
aps_http = { version = "1.2.0", features = ["tls", "gzip"] }

[dev-dependencies]
aps_test_bench = "0.1.0"

[profile.release]
opt-level = 3
lto = true
codegen-units = 1
panic = "abort"
```

## 3. Файл фиксации версий `Apm.lock`

Для обеспечения 100% детерминированной и воспроизводимой сборки (Reproducible Builds) APM автоматически генерирует `Apm.lock`, содержащий точные версии и криптографические контрольные суммы SHA-256:

```toml
# THIS FILE IS AUTOMATICALLY GENERATED BY APM. DO NOT EDIT.
version = 1

[[package]]
name = "aps_json"
version = "0.4.2"
source = "registry+https://pkg.aps-lang.org"
checksum = "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855"

[[package]]
name = "aps_http"
version = "1.2.0"
source = "registry+https://pkg.aps-lang.org"
checksum = "ca978112ca1bbdcafac231b39a23dc4da786eff8147c4e72b9807785afee48bb"
```
