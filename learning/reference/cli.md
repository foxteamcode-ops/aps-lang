# Справочник: Командная строка APS CLI (CLI Reference)

Компилятор **APS** поставляется в виде единого компактного исполняемого файла `aps` (или `aps.exe`), предоставляющего полный инструментарий разработчика без сторонних зависимостей.

---

## 1. Основные команды (Subcommands)

```bash
aps <subcommand> [flags] [files/directories]
```

| Команда | Описание |
|---|---|
| `aps run <file.aps>` | Сборка и немедленный запуск программы (JIT/AOT runner) |
| `aps build <file.aps>` | Компиляция файла или проекта в нативный исполняемый бинарный файл |
| `aps check <file.aps>` | Быстрая проверка синтаксиса, типов и правил памяти AMA без вызова LLVM |
| `aps test [path]` | Запуск встроенных модульных и интеграционных тестов |
| `aps fmt <file.aps>` | Автоматическое форматирование исходного кода по стандарту APS |
| `aps lint <file.aps>` | Статический анализ качества кода, предупреждения об утечках стилей |
| `aps doc <file.aps>` | Автогенерация HTML/Markdown документации из `///` комментариев |
| `aps repl` | Интерактивная консоль выполнения выражений APS Read-Eval-Print Loop |
| `aps bench [filter]` | Запуск тестов производительности с замером времени и памяти |

---

## 2. Ключевые флаги компилятора

| Флаг | Варианты | Назначение |
|---|---|---|
| `-O`, `--opt-level` | `0`, `1`, `2`, `3`, `s`, `z` | Уровень оптимизаций (0 — debug, 3 — максимальная скорость, s — минимальный размер) |
| `--emit` | `ast`, `hir`, `mir`, `ir`, `asm`, `obj`, `bin` | Остановка компиляции и вывод промежуточного представления |
| `-o`, `--output` | `<filename>` | Указание имени выходного исполняемого файла |
| `--target` | `x86_64-windows-msvc`, `x86_64-linux-gnu`, `aarch64-apple-darwin` | Кросс-компиляция для целевой архитектуры и ОС |
| `-v`, `--verbose` | — | Подробный вывод стадий компиляции и статистики оптимизаций |
| `--profile` | `debug`, `release` | Предустановленные профили сборки |

---

## 3. Примеры практического использования

```bash
# 1. Запуск программы в режиме разработки
aps run main.aps

# 2. Релизная сборка с оптимизацией O3 и выводом в app.exe
aps build main.aps -O 3 -o app.exe

# 3. Просмотр промежуточного LLVM IR
aps build main.aps --emit ir

# 4. Форматирование всех файлов проекта
aps fmt src/

# 5. Запуск всех тестов в каталоге
aps test tests/
```
