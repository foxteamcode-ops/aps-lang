# Практический проект: Инженерный калькулятор

## 1. Цель проекта
Калькулятор математических выражений и функций

## 2. Техническое задание
Реализовать законченную программу на языке APS, строго следующую инвариантам модели памяти AMA.

## 3. Структура файлов
- `main.aps` — точка входа и бизнес-логика.
- `README.md` — архитектурный разбор.

## 4. Последовательность разработки
1. Проектирование структур данных.
2. Реализация функций с правами `read`/`write`/`take`.
3. Интеграция с аренами `region`.
4. Тестирование и верификация.

## 5. Необходимая теория
Использование Уровней AMA (Local Memory, Region Memory) исключает паузы сборщика мусора и утечки ресурсов.

## 6. Требования
- Нулевое количество ошибок типов и памяти.
- Успешная компиляция компилятором APS.

## 7. Разбор реализации
В `main.aps` реализована типобезопасная логика с детерминированным временем выполнения.

## 8. Описание тестов
Проверяется вызовом `aps test learning/projects/01_calculator`.

## 9. Разбор архитектуры
Модульный дизайн без циклических зависимостей.

## 10. Возможные улучшения
Добавление сетевых протоколов и параллельной обработки.
