# APS Hyperion Real-Time HTTP Web Server (v1.0.0)

Настоящий высокопроизводительный веб-сервер, написанный на системном языке **APS (Advanced Performance Systems)**.

Сервер открывает реальный системный сокет TCP на порту `8080`, слушает входящие подключения и работает **непрерывно** в реальном времени, пока вы не остановите его сочетанием клавиш `Ctrl+C`.

---

## 1. Как это работает

- **Реальный TCP/IP сокет:** сервер использует нативный системный стек сокетов ОС (WinSock2 на Windows, BSD Sockets на Linux/macOS).
- **Непрерывный серверный цикл:** процесс не закрывается после старта — он висит в фоне и ожидает входящих HTTP-запросов от браузеров, curl или мобильных приложений.
- **Интерактивный лог в консоли:** при каждом переходе в браузере по ссылке сервер логирует в терминал метод, путь и IP-адрес клиента (`[HTTP Request] GET / from 127.0.0.1 -> 200 OK`).
- **Сборка -O3:** код компилируется в оптимизированный машинный код процессора с флагом LLVM `-O3`.

---

## 2. Запуск сервера одной командой

Откройте терминал PowerShell и выполните:

```powershell
cd "D:\APS\APS LANG\projects\backend_server"
aps run -O3
```

После этого в терминале появится сообщение:

```text
==================================================================
      APS HYPERION NATIVE HTTP SERVER (v1.0.0 RELEASE -O3)        
      Zero-GC Architecture | Real WinSock / BSD TCP Socket        
==================================================================
[STATUS] Сервер успешно запущен на порту 8080!
[LINK]   Откройте в любом браузере: http://localhost:8080
[INFO]   Сервер работает непрерывно (пока вы не нажмёте Ctrl+C).
[INFO]   Все входящие HTTP-запросы логируются ниже в реальном времени:
------------------------------------------------------------------
```

---

## 3. Проверка работы в браузере

1. Откройте любой браузер (Chrome, Edge, Яндекс, Firefox).
2. Перейдите по адресу: **`http://localhost:8080`**
3. В браузере мгновенно отобразится живой JSON-ответ от сервера APS:
   ```json
   {
     "status": "ONLINE",
     "server": "APS Hyperion v1.0.0",
     "language": "APS (Advanced Performance Systems)",
     "compiler": "LLVM 22 (-O3)",
     "memory_model": "AMA Zero-GC",
     "message": "Привет из реального веб-сервера на языке APS!"
   }
   ```
4. А в вашем терминале в реальном времени появится запись:
   ```text
   [HTTP Request] GET / from 127.0.0.1 -> 200 OK
     [APS-METRICS] Всего успешно обработано клиентских запросов: 1
   ```

---

## 4. Как остановить сервер

Чтобы штатно остановить сервер, просто нажмите в терминале:
**`Ctrl + C`**

При этом сработает блок детерминированной очистки `defer`, корректно закроет сокет и освободит сетевой порт `8080`.
